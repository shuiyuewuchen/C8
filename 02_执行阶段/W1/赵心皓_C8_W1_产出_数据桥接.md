## 2. 统一 Message schema

```json
{
  "msg_id": "m0001",
  "timestamp": "2026-05-11T09:00:00+08:00",
  "sender": {"wechat_id": "staff_teacher_01", "nickname": "助教-王老师"},
  "type": "text",
  "content": "【通知】5月16日前提交 G1 提案…",
  "media_ref": "",
  "reply_to": ""
}
```

`type` 支持 `text | image | file | voice | link | system`；
异构输入字段（`time/timestamp`、`text/content`、`id/msg_id/local_id`）在 normalize 阶段收敛。

## 3. 实跑证据

```bash
$ python3 data/generate_fixture.py
generated 168 messages, 168 labels -> sample_messages.jsonl

$ python3 skills/wechat-bridge/bridge.py --adapter fixture
bridged 168 messages -> outputs/messages.jsonl
types: ['file', 'image', 'link', 'text', 'voice']
```

- 消息数：**168**（R̂ ≥120，达成）
- 消息类型：**5 种**（R̂ ≥5，达成）
- 重复运行两次结果一致（fixture 适配器）
- 数据窗口：2026-05-11 09:00 ~ 2026-06-09 06:18
