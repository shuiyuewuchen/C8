## 2. Watcher 增量验证

```python
with tempfile.TemporaryDirectory() as td:
    cp = Path(td) / "cp.json"
    first, _ = incremental_messages(cp)   # 168 条
    second, _ = incremental_messages(cp)  # 0 条
```

实测：首次处理 **168** 条，二次处理 **0** 条——不重复处理已见消息。
