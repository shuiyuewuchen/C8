## 6. 诚实边界（请在评审时一并阅读）

1. **数据源是脱敏样本，不是生产微信群。** `cli` 适配器代码与安装文档已完成，
   但构建机器没有已登录的微信与系统权限，真实接入列为 W5 计划，未宣称已完成。
2. **96.4% 是内部上界。** 规则词表与标注集同源，外部效度需用独立人工标注的 50 条留出集复测。
3. **没有实现写回微信。** 这是有意的只读风险控制，写回仅保留架构位置。
4. **单条消息只解析第一个文件名**；批量上传会漏记。
5. **W5–W8 为计划项**，本包实际交付 W1–W4 的完整记录与可运行系统。

## 7. 面向真实使用者的价值

- **老师**：一句"C4 还有谁没交？"即可拿到名单，不用翻群文件；周报自动生成。
- **同学**：提交时立即知道 AI 日志是否缺失，避免"交了但被判未交"。
- **后续维护者**：6 个标准 Skill + 配置驱动 + 零依赖，接手成本低；
  换数据源只改 `bridge.py`，换图后端只改 `graph.py`。
